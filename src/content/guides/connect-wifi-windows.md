If you have a new computer, or your internet connection has stopped working, you may need to connect to Wi-Fi on Windows 11. Wi-Fi lets your PC connect to the internet without plugging a network cable into your router.

The process is usually simple: choose your home network, enter its password, and wait for Windows to connect. This guide shows you where to find the Wi-Fi controls and what to check if your network does not appear.

## Step 1: Make sure Wi-Fi is turned on

Before choosing a network, check that Wi-Fi is enabled on your computer. Some laptops have a keyboard shortcut or physical wireless switch, but most Windows 11 PCs let you control Wi-Fi from the taskbar.

1. Look at the right side of the taskbar, near the clock.
2. Select the **Network**, **Sound**, or **Battery** area to open Quick Settings. On many computers, the network icon looks like a Wi-Fi signal.
3. Find the **Wi-Fi** button.
4. If Wi-Fi is off, select it to turn it on.
5. If you see **Airplane mode**, make sure it is turned off unless you deliberately use it.

[SCREENSHOT: Windows 11 Quick Settings panel showing the Wi-Fi button switched on]

> **Tip:** If there is no Wi-Fi button, your PC may not have a wireless adapter, its driver may be missing, or Wi-Fi may be disabled by a hardware switch.

## Step 2: Choose your Wi-Fi network

Your Wi-Fi network name is also called its SSID. It is the name you see when your phone or computer searches for available wireless networks.

1. Select the network icon on the right side of the taskbar.
2. In Quick Settings, select the arrow beside the **Wi-Fi** button to show available networks.
3. Wait for the list to appear.
4. Find your home network name.
5. Select it.

If you are not sure which network is yours, check the label on your router or the information supplied by your internet provider. Some homes have more than one network name, such as separate 2.4 GHz and 5 GHz networks.

[SCREENSHOT: Windows 11 available Wi-Fi networks list with a network selected]

## Step 3: Enter your Wi-Fi password

Most home Wi-Fi networks are protected by a password. You may find it printed on a label on the router, unless you or your internet provider changed it.

1. After selecting your network, select **Connect**.
2. Type the Wi-Fi password into the **Enter the network security key** box.
3. Check the spelling carefully, including capital letters and numbers.
4. Select **Next**.
5. Wait for Windows to connect.

If you want Windows to connect automatically whenever the network is nearby, leave **Connect automatically** selected before you connect. This is convenient for your own home network.

[SCREENSHOT: Windows 11 Wi-Fi password box showing the Connect automatically option and Next button]

> **Careful:** The Wi-Fi password is case-sensitive. A capital letter is different from a lowercase letter, so check the router label carefully before trying again.

## Step 4: Check that you are connected

Windows should show that your chosen network is connected. You can also open a browser to check that the internet is working.

1. Select the network icon on the taskbar again.
2. Check that your network is marked **Connected**.
3. Open your web browser.
4. Visit a familiar website to test the connection.

If Windows says **Connected, secured** but websites will not load, your PC may be connected to the router but the router may not have an internet connection. Check whether other devices in your home can get online.

[SCREENSHOT: Windows 11 Quick Settings showing the connected Wi-Fi network]

> **Good to know:** Connecting to Wi-Fi and connecting to the internet are not quite the same thing. Your PC can have a wireless connection to the router even when the internet service itself is down.

## Step 5: Connect through Windows Settings

If you prefer, you can connect to a wireless network from the main Settings app.

1. Select **Start**, then open **Settings**.
2. Select **Network & internet**.
3. Select **Wi-Fi**.
4. Make sure the Wi-Fi switch is turned on.
5. Select **Show available networks**, if shown.
6. Choose your network, select **Connect**, and enter the password.
7. Select **Next** and wait for the connection.

The available options can vary slightly depending on your PC and Windows 11 version. If a menu looks different, type “Wi-Fi” into the Settings search box.

[SCREENSHOT: Windows 11 Settings > Network & internet > Wi-Fi showing available networks]

## Step 6: Connect to a hidden Wi-Fi network

Some networks do not broadcast their name, so they will not appear in the normal list. You can still connect if you know the exact network name and security details.

1. Open **Settings**.
2. Select **Network & internet**, then **Wi-Fi**.
3. Select **Manage known networks**.
4. Choose **Add network**.
5. Enter the exact network name in the **Network name** box.
6. Choose the correct **Security type** and enter the network security key.
7. Select **Connect automatically**, if you want Windows to remember it.
8. Select **Save**.

The network name and security type must match the router's settings. If you are unsure of them, ask the person who manages the network rather than guessing.

[SCREENSHOT: Windows 11 Add a network form showing Network name, Security type, and network security key]

## Troubleshooting: If you cannot connect to Wi-Fi

If the network is missing or Windows refuses the password, try these checks one at a time.

- **Check the password.** Make sure you are using the current Wi-Fi password, not the router's administrator password. Check capital letters and similar-looking characters.
- **Move closer to the router.** Walls and distance can weaken the wireless signal.
- **Turn Wi-Fi off and on.** Open Quick Settings, switch **Wi-Fi** off, wait a few seconds, and switch it on again.
- **Restart the router.** If no devices can connect, restart your router using its normal power procedure and wait for it to reconnect.
- **Restart your PC.** A restart can resolve a temporary wireless problem.
- **Run the network troubleshooter.** Open **Settings > System > Troubleshoot > Other troubleshooters**, then look for **Network and Internet** or a related network option if available.
- **Forget and reconnect.** Go to **Settings > Network & internet > Wi-Fi > Manage known networks**, select your network, choose **Forget**, then connect again and enter the password.

If Wi-Fi is missing completely, check whether your laptop has a wireless switch or keyboard shortcut. You can also open **Device Manager** and look under **Network adapters** to see whether a wireless adapter is listed. If you are not comfortable changing device settings, ask a trusted technician for help.

For more assistance, visit Microsoft's [Fix Wi-Fi connection issues in Windows](https://support.microsoft.com/windows/fix-wi-fi-connection-issues-in-windows-9424a1f7-6a3b-65a6-4d78-7f07eee84d2c) guide.

## Enjoy your wireless connection

Once Windows shows that your home network is connected, you can browse the web, check email, and use online apps. If you use a laptop in different places, repeat these steps for each trusted Wi-Fi network you need.
