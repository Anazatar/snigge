A new printer should make life easier, but getting it to work with your computer can feel like a puzzle. If you want to add printer Windows 11 users can connect one in a few straightforward steps, whether it uses a USB cable or your home Wi-Fi.

Windows can often find a printer and install what it needs automatically. If it does not, you can add it through Settings or use the printer maker's setup instructions. This guide explains both connection types and what to try if the printer does not appear.

## What you'll need

- Your Windows 11 PC.
- The printer and its power cable.
- A USB printer cable if you are connecting directly, or your Wi-Fi network name and password for a wireless printer.
- The printer's setup guide, if available.

## Step 1: Prepare your printer

Before connecting it to Windows, make sure the printer is ready. A printer that is switched off or still waiting for its first-time setup may not appear on your computer.

1. Remove any packaging, tape, or protective material from the printer.
2. Connect the power cable and turn the printer on.
3. Install the ink cartridges or toner if they are not already fitted.
4. Load some paper into the tray.
5. Check the printer's screen or indicator lights for any setup messages.

If the printer asks you to choose a language, region, or other basic settings, follow the instructions on its display. Keep the printer's manual nearby in case it uses a particular button sequence.

> **Tip:** If your printer has a display, use it to check that it is not showing an error such as “Paper jam,” “No paper,” or “Offline” before you begin.

## Step 2: Connect a wireless printer to your Wi-Fi network

A wireless printer connects to your home network, allowing your PC to print without a cable between the two devices. Your printer and computer usually need to be connected to the same network.

1. On the printer, open its **Wireless**, **Network**, or **Wi-Fi** setup menu. The exact name depends on the make and model.
2. Choose your home Wi-Fi network from the list.
3. Enter the Wi-Fi password when asked.
4. Wait for the printer to confirm that it is connected.
5. Check that your Windows PC is connected to the same home network.

Some printers offer Wi-Fi Protected Setup (WPS), which lets you connect using a button on a compatible router instead of typing the password. Use this only if both your router and printer support it, and follow the manufacturer's instructions.

[SCREENSHOT: Printer wireless setup screen showing a list of Wi-Fi networks]

> **Good to know:** A printer may support both 2.4 GHz and 5 GHz Wi-Fi, or only one of them. If it cannot join your network, check the printer's specifications and router settings.

## Step 3: Add the printer in Windows 11

Once the printer is switched on and connected, Windows can search for it. Keep the printer awake while you do this.

1. On your PC, select **Start**, then open **Settings**.
2. Select **Bluetooth & devices**.
3. Select **Printers & scanners**.
4. Select **Add device** beside **Add a printer or scanner**.
5. Wait while Windows searches for available printers.
6. When your printer appears, select **Add device** beside its name.
7. Follow any additional instructions on the screen.

Windows may take a short time to install the printer. When setup is complete, its name should appear in the list under **Printers & scanners**.

[SCREENSHOT: Windows 11 Settings > Bluetooth & devices > Printers & scanners, with Add device highlighted]

## Step 4: Connect a printer using a USB cable

If you prefer a wired connection, or your printer does not have Wi-Fi, you can usually connect it directly to your PC with a USB cable.

1. Turn on the printer.
2. Connect the square or printer-shaped end of the USB cable to the printer, if your cable has one.
3. Connect the other end to an available USB port on your PC.
4. Wait for Windows to detect the printer and install its driver.
5. If it does not appear automatically, open **Settings**.
6. Select **Bluetooth & devices**, then **Printers & scanners**.
7. Select **Add device** and wait for Windows to search.

A driver is software that helps Windows communicate with the printer. Windows often installs a suitable driver automatically, but some models need software from the manufacturer.

[SCREENSHOT: USB cable connecting a printer to a Windows 11 laptop or desktop PC]

> **Careful:** Use a USB cable that supports data, not just charging. If Windows does not detect the printer, try another USB port and check the printer manual for the correct cable type.

## Step 5: Install the printer manufacturer's software if needed

Some printers need a specific driver or setup application to provide all their features. If Windows cannot find the printer or does not install it correctly, check the manufacturer's support website.

1. Find the printer's make and exact model number. It is often printed on the front, back, or underside of the printer.
2. Open the official website for the printer manufacturer.
3. Go to its **Support**, **Downloads**, or **Drivers** section.
4. Search for your exact printer model.
5. Choose Windows 11 if you are asked to select an operating system.
6. Download and run the recommended driver or setup software.
7. Follow the instructions. Connect the printer by USB or Wi-Fi when the installer asks you to.

Avoid downloading drivers from unfamiliar websites or advertisements. If the manufacturer provides a setup app through the Microsoft Store, that may also be an option.

## Step 6: Print a test page

A test page confirms that Windows can communicate with the printer. It is a good idea to try this before printing a longer document.

1. Open **Start** and select **Settings**.
2. Select **Bluetooth & devices**.
3. Select **Printers & scanners**.
4. Choose your printer from the list.
5. Select **Printer properties**. Depending on the model, you may need to open **Print test page** from the available printer options.
6. Select **Print Test Page** if the button appears.

If the page prints, the connection is working. You can now choose this printer when printing from Word, a web browser, or another application.

[SCREENSHOT: Windows 11 printer properties window showing the Print Test Page button]

## Troubleshooting: If Windows cannot find your printer

If your printer does not appear, or a test page will not print, try these checks:

- **Restart both devices.** Turn the printer off and on again, then restart your PC.
- **Check the connection.** For Wi-Fi, confirm both devices are on the same network. For USB, reconnect the cable and try another port.
- **Check the printer display.** Clear any paper, ink, toner, or connection warnings shown on the printer.
- **Run the Windows troubleshooter.** Open **Settings**, select **System**, then **Troubleshoot** and **Other troubleshooters**. Look for **Printer** and select **Run** if it is available.
- **Check the printer's status.** Go to **Settings > Bluetooth & devices > Printers & scanners**, select your printer, and look for any status or queue options.
- **Check for a driver update.** Use Windows Update or the printer manufacturer's official support page.

If you cannot find a menu, use the search box in **Settings** and search for “Printers & scanners” or “Troubleshoot.” Menu wording can change slightly with Windows updates.

For more help, see [Microsoft's Windows support site](https://support.microsoft.com/windows) or the support site for your printer's manufacturer.

## Your printer is ready to use

Once Windows has added the printer and the test page has printed, you are ready to print documents and photos. Keep the printer connected to power and, for a wireless model, connected to your home Wi-Fi whenever you want to use it.
