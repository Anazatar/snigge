You don't have to use a mouse for every task on your computer. A few **Windows keyboard shortcuts** can help you open apps, find files, copy text, and move between windows with less clicking.

A keyboard shortcut is a combination of keys that performs an action when you press them together. You only need to learn a few at a time, and you can keep using your mouse whenever that feels easier. These shortcuts work in Windows 11 and most also work in Windows 10.

## Step 1: Copy and paste with Ctrl + C and Ctrl + V

Copying and pasting is one of the most useful things you can do on a computer. It lets you duplicate text, pictures, and files without typing or creating them again.

1. Select the text or file you want to copy.
2. Hold down **Ctrl** and press **C**.
3. Click where you want the copy to go.
4. Hold down **Ctrl** and press **V** to paste it.

[SCREENSHOT: Text selected in a Windows app with the Ctrl+C and Ctrl+V shortcuts shown]

The original item stays where it is. Copying creates another version in the place where you paste it.

> **Tip:** Think of **Ctrl + C** as “copy” and **Ctrl + V** as “paste.” These shortcuts work in many apps, including email, Word, and File Explorer.

## Step 2: Cut and paste with Ctrl + X

If you want to move something rather than make a copy, use Cut and Paste.

1. Select the text or file you want to move.
2. Hold down **Ctrl** and press **X**.
3. Go to the place where you want it to appear.
4. Hold down **Ctrl** and press **V**.

[SCREENSHOT: File Explorer showing a selected file and the Ctrl+X then Ctrl+V shortcut]

For text, Cut removes it from its original position when you paste it somewhere else. For a file, it prepares the file to be moved to another folder when you paste.

## Step 3: Undo a mistake with Ctrl + Z

If you accidentally delete a sentence while typing or make an unwanted change, Undo can often put things right.

1. In the app where you made the change, hold down **Ctrl**.
2. Press **Z**.
3. If needed, press **Ctrl + Z** again to undo another recent action.

[SCREENSHOT: A document showing the Undo button and Ctrl+Z shortcut]

Undo works in many programs, but it cannot reverse every action. For example, it may not recover a file permanently deleted from your computer.

> **Good to know:** Many apps also have a **Redo** command. In many Windows programs, **Ctrl + Y** repeats an action you have undone.

## Step 4: Select everything with Ctrl + A

This shortcut selects all the items in the current area. It is useful when you want to copy a whole paragraph, select every file in a folder, or highlight all the text in a document.

1. Click inside the document, text box, or folder you want to work with.
2. Hold down **Ctrl** and press **A**.
3. Check what has been selected before taking another action.

[SCREENSHOT: File Explorer with all files in a folder selected after Ctrl+A]

Be careful when using this shortcut in a folder. If you press Delete after selecting everything, you may send all the selected files to the Recycle Bin.

## Step 5: Find a word or phrase with Ctrl + F

When a document or webpage is long, you don't need to read every line to find a particular word.

1. Open the document, webpage, or app you want to search.
2. Hold down **Ctrl** and press **F**.
3. Type the word or phrase you are looking for.
4. Press **Enter** or use the arrows in the search box to move between matches.
5. Close the search box when you are finished.

[SCREENSHOT: Browser or document with the Ctrl+F Find box open]

This shortcut is especially useful for finding a name, date, or phrase in a long document. The exact search box may look different depending on the app.

## Step 6: Open File Explorer with Windows key + E

File Explorer is the Windows app you use to browse folders, documents, pictures, and other files. This shortcut opens it straight away.

1. Find the **Windows** key on your keyboard. It usually has a four-pane Windows logo.
2. Hold down the **Windows** key.
3. Press **E**.
4. Release both keys when File Explorer opens.

[SCREENSHOT: Keyboard highlighting the Windows key and E key, alongside an open File Explorer window]

You can then select **Documents**, **Downloads**, **Pictures**, or another folder from the left-hand pane.

## Step 7: Lock your PC with Windows key + L

If you need to step away from your computer, lock the screen so someone else cannot open your desktop without signing in.

1. Hold down the **Windows** key.
2. Press **L**.
3. Your computer will show the lock screen.
4. Sign in again with your usual PIN, password, or other sign-in method when you return.

[SCREENSHOT: Windows 11 lock screen showing the sign-in area]

> **Careful:** Locking your PC protects access to your open session, but it does not save unsaved work. Save important documents before stepping away.

## Step 8: Switch between open apps with Alt + Tab

If you have several windows open, this shortcut lets you move between them without clicking each one on the taskbar.

1. Hold down **Alt**.
2. Press **Tab** once to show your open windows.
3. Keep holding **Alt** and press **Tab** again to move through the choices.
4. Release **Alt** when the window you want is highlighted.

[SCREENSHOT: Windows 11 task switcher showing several open app windows]

This is handy when you are copying information from a webpage into a document or moving between email and another app.

## Step 9: Open Settings with Windows key + I

You can use this shortcut to open Windows Settings directly, rather than finding it in the Start menu.

1. Hold down the **Windows** key.
2. Press **I**.
3. Release both keys.
4. Select the settings category you need, such as **System**, **Bluetooth & devices**, or **Personalization**.

[SCREENSHOT: Windows 11 Settings home page opened with Windows+I]

This shortcut works in Windows 11 and Windows 10, although the Settings layout differs between the two versions.

## Step 10: Take a screenshot with Windows key + Shift + S

A screenshot is a picture of what is displayed on your screen. This shortcut opens the Windows screen capture tool so you can select the part you want.

1. Hold down the **Windows** key and **Shift**.
2. Press **S**.
3. When the screen dims and the capture toolbar appears, choose a capture shape.
4. Click and drag around the area you want to capture.
5. Select the notification that appears if you want to edit or save the image in Snipping Tool.

[SCREENSHOT: Windows 11 Snipping Tool toolbar showing the screen capture options]

The screenshot is copied to the clipboard, which is a temporary place Windows uses to hold copied items. You can paste it into an email or document with **Ctrl + V**.

## Troubleshooting: If a shortcut doesn't work

If a key combination does not seem to do anything, try these checks:

- **Press the keys together:** Hold down the first key, press the second, and then release both. You do not need to press them at exactly the same instant.
- **Check the keyboard layout:** Laptop keyboards sometimes combine keys or require the **Fn** key for certain functions.
- **Make sure the right app is active:** Shortcuts such as **Ctrl + F** work inside an app that supports Find. Click the document or window first.
- **Try the menu instead:** Most common actions, such as Copy, Paste, and Undo, are also available from an app's menus or right-click menu.
- **Check for a different shortcut:** Some programs use their own key combinations, so a shortcut may behave differently in a particular app.

## Start with the shortcuts you'll use most

You don't need to memorize all ten at once. Try **Ctrl + C**, **Ctrl + V**, and **Windows key + E** first, then add another shortcut when you feel comfortable. With a little practice, these small time-savers can make everyday computer tasks easier.
