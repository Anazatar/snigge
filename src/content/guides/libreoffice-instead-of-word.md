If you are used to Microsoft Word, switching to a different word processor can feel like a big change. You may be wondering whether you can still write letters, prepare documents, and open files that other people send you.

LibreOffice is a free office suite that includes Writer, a word processor with many of the tools you may recognize from Word. This guide to LibreOffice for beginners walks through the basics, including creating a document, formatting text, and working with Microsoft Word files.

## What you'll need

- LibreOffice installed on your computer. You can get it from the official LibreOffice website.
- A keyboard and mouse or trackpad.
- An internet connection if you need to download LibreOffice or share files online.

## Step 1: Open LibreOffice Writer

LibreOffice is a collection of office programs. Writer is the one you use for letters, reports, and other text documents.

1. Open the applications menu on your computer.
2. Search for **LibreOffice Writer** and select it. On some systems, you can open LibreOffice first and choose **Writer Document**.
3. Wait for a blank document to appear.
4. If you see the LibreOffice Start Center instead, choose **Writer Document** to begin.

[SCREENSHOT: LibreOffice Start Center showing the Writer Document option]

The Writer window has a large white page in the middle, menus across the top, and toolbars with commonly used controls. The layout is different from recent versions of Word, but the main ideas are similar.

> **Good to know:** LibreOffice menus can look slightly different depending on your version and operating system. If you cannot find a command, use the Help menu or the search field for commands if your version provides one.

## Step 2: Create and save your first document

You can start typing as soon as the blank page opens. It is a good idea to save the document early, so you have a file to return to if something goes wrong.

1. Click near the top of the white page.
2. Type a few words, such as the heading for a letter or a shopping list.
3. Choose **File** from the menu bar, then select **Save As**.
4. Choose a folder where you will be able to find the document, such as **Documents**.
5. Type a name in the **File name** box.
6. Check the file type. For a document you plan to keep editing in LibreOffice, use **ODF Text Document (.odt)**.
7. Click **Save**.

[SCREENSHOT: LibreOffice Writer Save As window with the file name and ODT file type visible]

Writer saves documents in the OpenDocument Text format by default. This is an open file format used by LibreOffice and other office programs. You can also save a copy in Microsoft Word format when you need to share it with someone who uses Word.

> **Tip:** Press **Ctrl-S** regularly to save your latest changes. On a Mac, use **Command-S** instead.

## Step 3: Format text so it is easy to read

Formatting changes the appearance of text. You can make headings stand out, emphasize important words, and organize information into sections.

1. Use your mouse to select the words you want to change.
2. To make text bold, click the **Bold** button on the toolbar, or press **Ctrl-B**. On a Mac, use **Command-B**.
3. To make text italic, click **Italic** or press **Ctrl-I**. On a Mac, use **Command-I**.
4. To change the text size, select the text and choose a size from the font-size box on the toolbar.
5. To change the font, select the text and choose a font from the font-name box.

For document headings, it is better to use Writer's built-in paragraph styles rather than simply making a line larger and bold. Select the heading line, open the **Styles** menu or the paragraph style list on the toolbar, and choose a style such as **Heading 1** or **Heading 2**.

[SCREENSHOT: Writer toolbar showing font, font size, Bold and Italic controls, with a heading selected]

> **Careful:** Avoid using lots of different fonts and sizes in one document. A small number of consistent styles usually makes a letter or report easier to read.

## Step 4: Use lists and align your paragraphs

Lists and paragraph alignment can make information easier to follow. These tools are useful for instructions, shopping lists, meeting notes, and simple reports.

1. To make a list, click where you want it to begin.
2. Select the **Bulleted List** button for items marked with dots, or the **Numbered List** button for items in order.
3. Type the first item and press **Enter** to start the next one.
4. To finish the list, press **Enter** twice after the last item.
5. To align a paragraph, click inside it and choose **Align Left**, **Center**, **Align Right**, or **Justified** from the toolbar or the **Format** menu.

[SCREENSHOT: A Writer document showing a numbered list and paragraph alignment buttons]

## Step 5: Open and save Microsoft Word documents

LibreOffice Writer can open many Microsoft Word documents, including common **.docx** and **.doc** files. This means you can often work with a document someone sends you without having Microsoft Word installed.

1. Open Writer.
2. Choose **File**, then **Open**.
3. Find the Word document on your computer, select it, and click **Open**.
4. Make your changes as needed.
5. If you want to keep the original Word format, choose **File**, then **Save As**.
6. In the file type list, choose **Word 2007–365 (.docx)** if that option is available, then click **Save**.
7. If a message asks whether to use the Word format or the ODF format, choose the Word format when you need to send the file to someone who uses Microsoft Word.

[SCREENSHOT: LibreOffice Writer Save As dialog with Word 2007–365 (.docx) selected]

> **Good to know:** Complex Word documents may not look exactly the same in Writer. Fonts, page layouts, tracked changes, or special formatting can shift. If the document is important, check the saved copy before sending it.

## Step 6: Export a document as a PDF

A PDF is a file format designed to keep a document's layout looking consistent on different devices. It is useful when you want someone to read or print a document without editing it.

1. Open the document in Writer.
2. Choose **File** from the menu bar.
3. Select **Export As**, then choose **Export as PDF**. In some versions, you may also see a PDF export button on the toolbar.
4. Review the settings if a PDF Options window appears.
5. Click **Export**, choose where to save the file, enter a name, and confirm.

[SCREENSHOT: LibreOffice Writer File menu showing Export As and Export as PDF]

Open the PDF after exporting to check that the pages, images, and text look as you expect. Keep the original Writer or Word document too if you think you may want to edit it later.

## Troubleshooting: If something looks different

**A Word document does not look quite right.** Some fonts or advanced formatting may not transfer perfectly. Try opening the document in Writer and checking the page layout, or ask the sender to provide a PDF if you only need to read it.

**I cannot find a file I saved.** In Writer, choose **File**, then **Recent Documents**, or open the folder you selected in the Save As window. Check the file name and the folder carefully.

**The document keeps saving as ODT.** Choose **File > Save As** and select **Word 2007–365 (.docx)** from the file type list when you need a Word-compatible copy. Keep an ODT version if you will continue working mainly in LibreOffice.

**The menus do not match these instructions.** Your LibreOffice version or operating system may use a slightly different layout. Look for the same command under **File**, **Format**, or **Styles**, or use the Help menu to search for it.

## Give LibreOffice a try

LibreOffice Writer can handle everyday writing tasks such as letters, lists, and reports, and it can work with many Microsoft Word files. Start with a simple document, save it as you go, and use the Word or PDF format when that best suits the person receiving it.
