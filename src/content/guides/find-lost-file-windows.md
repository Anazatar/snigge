You know you saved a document or photo, but now you can't remember where it went. If you need to **find lost file Windows** users can try several built-in tools before assuming the file has disappeared.

Windows 11 can search by file name, type, or words inside some documents. You can also check familiar folders, the Recycle Bin, and cloud storage. Work through the steps below in order, and avoid saving lots of new files until you've checked whether the missing item can be recovered.

## Step 1: Search from the Start menu

The quickest place to begin is Windows Search. It can look for files as well as apps and settings.

1. Select **Start** on the taskbar, or press the **Windows** key.
2. Start typing the name of the missing file.
3. Look through the results for a match.
4. If you see the file, right-click it and choose **Open file location** if that option is available.
5. Make a note of the folder where Windows found it.

[SCREENSHOT: Windows 11 Start menu search showing a file result]

If you cannot remember the full name, type just one or two words that might be in it. Try a distinctive word rather than a common one such as “document.”

> **Tip:** Search for part of the file name first. A file called “Garden plans April” may still appear if you search for “Garden” or “plans.”

## Step 2: Search in File Explorer

File Explorer lets you search through folders and narrow down the results.

1. Select the **File Explorer** icon on the taskbar, or press **Windows key + E**.
2. Select **This PC** in the left-hand pane to search the main locations on your computer.
3. Select the search box near the top-right corner.
4. Type the file name or a word you remember.
5. Press **Enter** and wait for the results.

[SCREENSHOT: File Explorer open to This PC with the search box highlighted]

Searching all of **This PC** can take longer than searching one folder. If you remember that the file was in **Documents** or **Downloads**, open that folder first and search there.

You can also sort the results by name or date. Select the relevant column heading, such as **Date modified**, to help spot a file you worked on recently.

## Step 3: Check the usual folders

Files often end up in a different folder from the one you expected. Check the places where Windows and common apps usually save them.

1. Open **File Explorer**.
2. Select **Home** or **This PC** in the left-hand pane.
3. Open **Documents** and look for the missing file.
4. Check **Downloads** for files saved from websites or email attachments.
5. Check **Pictures** for photos and images, and **Desktop** for items saved directly to the desktop.

[SCREENSHOT: File Explorer showing the Documents, Downloads, Pictures, and Desktop folders]

If you use Microsoft Word, Excel, or another app, open that app and check its recent files list. It may show the name and location of something you opened or saved recently.

> **Good to know:** The file's name and the app you used to create it can help narrow the search. A Word document may have a `.docx` ending, while a PDF usually ends in `.pdf`.

## Step 4: Search by file type or date

If you cannot remember the name, try searching for the kind of file you need. File extensions are the letters after the final dot in a file name, and they indicate the file format.

1. Open **File Explorer** and select **This PC**.
2. Click the search box.
3. Type a file extension, such as `.pdf`, `.docx`, `.xlsx`, or `.jpg`.
4. Press **Enter**.
5. Review the results and sort them by **Date modified** if you know roughly when you last used the file.

[SCREENSHOT: File Explorer search results for a file extension, sorted by Date modified]

You can also try a word that may appear inside the document. Windows may be able to find words in some indexed file types, but this depends on your search settings and the file format.

## Step 5: Look in the Recycle Bin

If you may have deleted the file by accident, check the Recycle Bin before trying anything else.

1. Look for **Recycle Bin** on your desktop.
2. Double-click it to open.
3. Browse the list or use its search box to look for the file.
4. If you find the right item, right-click it.
5. Select **Restore**.

[SCREENSHOT: Windows 11 Recycle Bin showing a file and the Restore option]

Windows will normally put the file back in its original folder. If you cannot see the Recycle Bin on your desktop, search for “Recycle Bin” from **Start**.

> **Careful:** Files deleted from a USB drive, network location, or some cloud services may not appear in the Recycle Bin. If you think a file is important, avoid emptying the bin until you are sure you no longer need anything in it.

## Step 6: Check OneDrive or another cloud service

If you use OneDrive, Google Drive, Dropbox, or another cloud storage service, the file may be online rather than in a folder on your PC. Cloud storage keeps files on internet-connected servers so you can access them from more than one device.

1. Open **File Explorer** and look for **OneDrive** in the left-hand pane, if you use it.
2. Open the folder and search for the file.
3. If it is not there, visit the cloud service's official website and sign in to the account you normally use.
4. Search the online file list for the name.
5. Check the service's **Recycle Bin** or **Trash** if you may have deleted it.

[SCREENSHOT: File Explorer showing OneDrive in the navigation pane]

If you use more than one Microsoft account, check that you are signed in to the right one. A file saved to a work or family account may not appear in your personal account.

## Step 7: Check recent files in the app you used

Sometimes the easiest way to locate a file is to open the program that created it.

1. Open the app you used, such as **Word**, **Excel**, or **Paint**.
2. Look for **Recent** or **Open** on its start screen.
3. Find the file in the recent list, if it appears.
4. If the app shows a location or folder, use it to open the file.
5. Once the file is open, choose **File** > **Save as** if you want to save a fresh copy in a folder you can find easily.

[SCREENSHOT: Microsoft Word start screen showing the Recent files list]

Recent lists may show files that have been moved or deleted, so an entry does not guarantee the file is still available. If it will not open, use the location shown (if available) to continue searching.

## Troubleshooting: If you still can't find the file

If the file does not appear in any of these places, try the following:

- **Check the spelling:** Search for a shorter part of the name or a different word you remember.
- **Look in another Windows account:** If more than one person uses the PC, the file may be saved in another person's account folder.
- **Check external drives:** Connect any USB drives or external disks you used when saving the file, then search them in File Explorer.
- **Check cloud accounts:** Make sure you are signed in to the correct OneDrive or other cloud account.
- **Consider whether it was moved or renamed:** Search by file type and date rather than the original name.

If you believe the file was permanently deleted, stop using the drive as much as possible. New activity can overwrite space where deleted data was stored. Check whether you have a backup or contact a reputable data-recovery professional if the file is especially important.

## Make your files easier to find next time

Once you find the file, consider moving it into a clearly named folder such as **Documents**, **Pictures**, or a folder for a particular project. Use a name that includes a subject and date, and keep a backup of important files so you can find another copy if needed.
