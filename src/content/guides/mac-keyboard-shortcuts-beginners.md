If you are new to a Mac, using the keyboard can sometimes feel different from using a Windows PC. You may be used to pressing **Ctrl** for common tasks, only to discover that your Mac uses a different key.

The good news is that a few Mac keyboard shortcuts can make everyday tasks much quicker. You do not need to memorize dozens of combinations. Start with these 10 useful shortcuts, practice them as you go, and keep this guide nearby until they feel familiar.

## What you'll need

- A Mac keyboard, either built into a MacBook or connected to your Mac.
- A little time to try each shortcut.

**First, find the Command key.** Most Mac shortcuts use the **Command (⌘)** key. It is near the space bar and is marked with the ⌘ symbol. When this guide says **Command**, hold that key down while pressing the other key.

## Step 1: Copy and paste text or files

<text>**Copy:** Command (⌘) + C</text>

<text>**Paste:** Command (⌘) + V</text>

These are two of the most useful shortcuts on any computer.

1. Select the text or file you want to copy.
2. Hold **Command** and press **C**.
3. Move the cursor to where you want the copy to appear, or open the folder where you want to place the copied file.
4. Hold **Command** and press **V**.

Copying leaves the original in place. If you want to move a file rather than make another copy, you can copy it, then use **Option + Command + V** in the destination folder to move it there.

> **Tip:** If you are used to Windows, remember that Mac uses **Command** for many shortcuts where Windows uses **Ctrl**.

## Step 2: Cut and undo a mistake

<text>**Cut:** Command (⌘) + X</text>

<text>**Undo:** Command (⌘) + Z</text>

Cut removes selected text from its current position so you can paste it somewhere else. In many Mac apps, **Command + X** works with text, but it does not cut files in Finder in the same way it does on Windows.

1. Select a word, sentence, or paragraph in an app that supports cutting.
2. Hold **Command** and press **X**.
3. Click where you want the text to go.
4. Hold **Command** and press **V**.
5. If you make a mistake, press **Command + Z** to undo the last action.

Undo is especially helpful when you delete something by accident or make an unwanted change. Many apps also offer **Edit > Undo** in the menu bar.

> **Careful:** Undo usually reverses the most recent action. If you continue working afterward, check what is selected before pressing the shortcut again.

[SCREENSHOT: A text document with the Edit menu open and Undo highlighted]

## Step 3: Select everything

<text>**Select all:** Command (⌘) + A</text>

This shortcut selects all the content in the current area. It can select all text in a document, all files in a Finder window, or all items in a list.

1. Click inside the document, folder window, or list you want to work with.
2. Hold **Command** and press **A**.
3. Check that the items you want are highlighted before doing anything else.
4. Copy, move, format, or delete the selection as needed.

The shortcut applies to the active app or area, not necessarily everything on your Mac.

[SCREENSHOT: A Finder window with all files selected after pressing Command + A]

## Step 4: Find a word or phrase

<text>**Find:** Command (⌘) + F</text>

Use this shortcut to search within a document, webpage, or many other apps.

1. Open the document or webpage you want to search.
2. Hold **Command** and press **F**.
3. Type the word or phrase into the search field that appears.
4. Press **Return** or use the on-screen arrows to move between matches.
5. Press **Escape** when you have finished searching.

This is useful when you are reading a long article or looking for a particular name in a document.

[SCREENSHOT: A browser window with the Find field open and a word highlighted on the page]

## Step 5: Switch between open apps

<text>**Switch apps:** Command (⌘) + Tab</text>

If you have several apps open, you do not need to find each one with the mouse.

1. Hold down **Command**.
2. While holding it, press **Tab** once to show the app switcher.
3. Keep holding **Command** and press **Tab** again to move through the open apps.
4. Release **Command** when the app you want is highlighted.

You can also press **Shift + Command + Tab** to move backward through the list. This shortcut switches between open apps, not between individual windows of the same app.

> **Good to know:** If you have several windows open in one app, **Control + Down Arrow** can show that app's windows through Mission Control, depending on your keyboard settings.

[SCREENSHOT: The macOS app switcher showing several open app icons]

## Step 6: Take a screenshot of the whole screen

<text>**Full-screen screenshot:** Shift + Command (⌘) + 3</text>

A screenshot is an image of what is currently displayed on your screen. This shortcut captures the entire screen.

1. Arrange the screen so it shows what you want to save.
2. Hold **Shift** and **Command** together.
3. Press **3**.
4. Look for the screenshot thumbnail that briefly appears in a corner of the screen.
5. By default, the screenshot is saved as a file on your desktop. Open it if you want to view or share it.

If you use more than one display, the Mac may capture each display separately.

[SCREENSHOT: Mac desktop with the screenshot thumbnail appearing in the corner after Shift + Command + 3]

## Step 7: Capture just part of the screen

<text>**Selected-area screenshot:** Shift + Command (⌘) + 4</text>

You may not want to capture the whole screen. This shortcut lets you select just the area you need.

1. Hold **Shift** and **Command** together.
2. Press **4**. Your pointer changes to a crosshair.
3. Click and drag to draw a box around the area you want to capture.
4. Release the mouse or trackpad button to take the screenshot.
5. Find the saved image on your desktop.

If you change your mind before releasing, press **Escape** to cancel. You can also press the space bar after starting the shortcut to capture a window instead of drawing a selection.

[SCREENSHOT: Mac screen with the screenshot crosshair selecting a small area]

## Step 8: Open a new Finder window

<text>**New Finder window:** Command (⌘) + N</text>

Finder is the Mac app you use to browse files and folders. This shortcut opens a new Finder window when Finder is active.

1. Click the **Finder** icon in the Dock, the row of app icons usually at the bottom of the screen.
2. Hold **Command** and press **N**.
3. A new Finder window opens.
4. Use the sidebar to visit folders such as **Documents**, **Downloads**, or **Desktop**.

The same shortcut may create a new window in other apps too, such as a new document in some word-processing apps.

[SCREENSHOT: Mac desktop with a new Finder window open and its sidebar visible]

## Step 9: Quickly open Spotlight Search

<text>**Spotlight:** Command (⌘) + Space bar</text>

Spotlight is the Mac's built-in search tool. It can help you find apps, files, settings, and information without browsing through folders.

1. Hold **Command** and press the **Space bar**.
2. Type the name of an app, file, or setting.
3. Look through the results.
4. Press **Return** to open the highlighted result.

For example, type **Calculator** to find the Calculator app, or enter part of a document's name to look for it.

If this shortcut does not open Spotlight, search for **Spotlight** in **System Settings** and check the keyboard shortcut settings. Another app or a changed keyboard setting may be using the same combination.

[SCREENSHOT: Spotlight search field open in the center of a Mac screen with Calculator in the results]

## Step 10: Lock your Mac when you step away

<text>**Lock screen:** Control + Command (⌘) + Q</text>

This shortcut takes you to the Mac's Lock Screen. You will need to sign in again to return to your work, according to your Mac's login settings.

1. Save any important work.
2. Hold **Control** and **Command** together.
3. Press **Q**.
4. Your Mac switches to the Lock Screen.

Locking your Mac is a useful habit when you leave your desk, especially if other people could access the computer.

## Troubleshooting: What if a shortcut does not work?

If a shortcut does not seem to do anything, check these points:

- **Make sure the app is active.** Some shortcuts only work in certain apps or when a particular window is selected.
- **Press the keys together.** Hold the modifier keys, such as **Command** or **Shift**, and then tap the final key.
- **Check the key labels.** On some third-party keyboards, the key marked **Windows** may act as **Command** when connected to a Mac. The layout depends on the keyboard and its settings.
- **Look for a menu command.** Open the app's menu bar and check **File**, **Edit**, or another relevant menu. If a shortcut is available, it is often shown beside the command.
- **Check keyboard settings.** If a shortcut has been changed, search for **Keyboard Shortcuts** in **System Settings**.

The shortcuts in this guide apply to current versions of macOS and many common apps. Some apps use different shortcuts, and a few actions may not be available in every situation.

## Start with a few shortcuts at a time

You do not have to learn all 10 Mac keyboard shortcuts today. Try **Command + C**, **Command + V**, and **Command + Z** first, then add the others as you need them. With a little practice, these small key combinations can make everyday tasks feel much easier.
