If you want to show someone what is on your computer screen, save a message, or keep a copy of an error, taking a screenshot is a simple way to do it. If you've been wondering **how to screenshot on Windows**, you don't need special software for most everyday tasks.

Windows 11 includes built-in keyboard shortcuts and a tool called Snipping Tool. You can capture the whole screen, a single window, or just the part you want to share. The steps below explain where to find the picture afterward, too.

## Step 1: Capture the whole screen

The quickest way to take a screenshot of everything on your display is to use the Print Screen key. It may be labelled **PrtScn**, **PrtSc**, or something similar on your keyboard.

1. Arrange your screen so it shows what you want to capture.
2. Press the **PrtScn** key.
3. Open an app where you can paste an image, such as **Paint** or an email message.
4. Press **Ctrl + V** to paste the screenshot.
5. If you use Paint, select **File** > **Save as** to save it as an image.

[SCREENSHOT: Windows keyboard showing the PrtScn key]

On many Windows 11 PCs, pressing **PrtScn** opens the screen capture interface instead of immediately copying the whole screen. If that happens, use the selection controls to capture the area you want, or follow Step 2.

> **Good to know:** A screenshot copied to the clipboard is not automatically saved as a file. The clipboard is a temporary place where Windows keeps copied items until you paste them or copy something else.

## Step 2: Capture part of the screen with Snipping Tool

Snipping Tool is built into Windows 11 and lets you select exactly what appears in the screenshot. It is useful when you only want to show one part of a page.

1. Press **Windows key + Shift + S** on your keyboard.
2. The screen will dim and a small capture toolbar will appear.
3. Choose the type of snip you want, such as a rectangle, a freeform shape, a window, or the full screen.
4. For a rectangular capture, click and drag around the area you want.
5. Release the mouse button to take the screenshot.

[SCREENSHOT: Windows 11 Snipping Tool capture toolbar showing the available snip modes]

The screenshot is copied to the clipboard. A notification may appear; select it to open the capture in Snipping Tool, where you can make changes and save it.

> **Tip:** For most everyday screenshots, **Windows key + Shift + S** is a handy shortcut to remember. You can use it whenever you need to capture just one part of the screen.

## Step 3: Capture one window

If you want to capture a single program window without including the rest of your desktop, use a keyboard shortcut.

1. Click the window you want to capture so it is active.
2. Hold down **Alt** and press **PrtScn**.
3. Open **Paint**, an email, or another app that accepts images.
4. Press **Ctrl + V** to paste the screenshot.
5. Save it if you want to keep a separate image file.

[SCREENSHOT: Two open Windows windows, with one selected as the active window]

This method captures the active window rather than the whole desktop. If your keyboard does not have a separate Print Screen key, check whether it shares a key with another function. You may need to hold **Fn** as well, depending on your keyboard.

## Step 4: Save a screenshot as a file automatically

You can use a shortcut that captures the whole screen and saves the image directly, without needing to paste it into another app.

1. Press **Windows key + PrtScn**.
2. Your screen may briefly dim to show that the screenshot was taken.
3. Open **File Explorer**.
4. Select **Pictures** in the left-hand navigation pane.
5. Open the **Screenshots** folder.

[SCREENSHOT: File Explorer showing Pictures > Screenshots with saved screenshot files]

If your keyboard requires the **Fn** key for Print Screen, try **Windows key + Fn + PrtScn**. On some laptops, the key combination may differ, so check the keyboard labels or the manufacturer's instructions if it does not work.

> **Good to know:** If OneDrive is set to back up your Pictures folder, your screenshots may be stored in a OneDrive Pictures folder instead. Look in File Explorer under **OneDrive** if you cannot find them in the usual location.

## Step 5: Open and edit a screenshot

You may want to crop a screenshot, highlight something, or remove parts that are not relevant before sharing it.

1. Open **File Explorer** and find your screenshot.
2. Double-click the image to open it in the default photo viewer.
3. If you want to edit it, right-click the image and choose **Open with** > **Paint**, or open Paint and select **File** > **Open**.
4. Use Paint's selection, crop, or drawing tools to make the changes you need.
5. Select **File** > **Save** to keep the changes, or **Save as** to create a separate edited copy.

[SCREENSHOT: Windows Paint showing a screenshot with the Crop tool available]

If you are editing an image you may want to keep unchanged, choose **Save as** and give the edited version a different name. That way, you still have the original screenshot.

## Troubleshooting: If your screenshot won't save

If a shortcut does not seem to work or you cannot find the image, try these checks:

- **Nothing happens when you press PrtScn:** Try **Fn + PrtScn** or **Windows key + Shift + S**. Laptop keyboards sometimes combine Print Screen with another function.
- **The screenshot isn't in the Screenshots folder:** If you used **PrtScn** or **Alt + PrtScn**, the image may only be on the clipboard. Paste it into Paint and save it.
- **Snipping Tool doesn't open:** Open **Start**, type “Snipping Tool,” and select the app. You can also check for updates in Microsoft Store.
- **You can't find the saved image:** Search File Explorer for “Screenshots” or look in **Pictures** and **OneDrive**.
- **The shortcut behaves differently:** Open **Settings** and search for “Print Screen.” Windows may offer a setting that controls whether the Print Screen key opens screen capture.

> **Careful:** Before sharing a screenshot, check that it does not show private details such as passwords, account numbers, personal messages, or other information you would rather keep private.

## You're ready to take screenshots

Once you remember **Windows key + Shift + S**, capturing part of your screen is quick and straightforward. Use the full-screen shortcut when you need everything, and check the Screenshots folder when you want to find an image saved automatically.
