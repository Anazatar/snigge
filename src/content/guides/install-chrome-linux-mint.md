If you use Google Chrome on a Windows PC and have moved to Linux Mint,
you may want the same browser on your new computer. The good news is
that you can install Chrome on Linux Mint without using complicated
commands.

The simplest method is to download the official Linux installer from
Google's website. This guide walks you through the process, including
how to open Chrome for the first time and what to check if the
installation does not work.

## What you'll need

-   A Linux Mint computer connected to the internet.
-   Your account password, in case Linux Mint asks you to approve the
    installation.
-   A few minutes to download and install the browser.

## Step 1: Open the official Google Chrome download page

Start by visiting Google's own website. This helps you avoid unofficial
downloads or websites offering modified versions of the browser.

1.  Open the web browser already installed on Linux Mint, such as
    Firefox.
2.  Click the address bar at the top of the browser window.
3.  Type **https://www.google.com/chrome/** and press **Enter**.
4.  Wait for the Google Chrome download page to appear.
5.  Choose **Download Chrome**.

\[SCREENSHOT: Official Google Chrome download page open in a browser,
with the Download Chrome button visible\]

> **Careful:** Download Chrome from Google's official website. Avoid
> third-party download sites, even if they offer a file with a similar
> name.

## Step 2: Choose the correct Linux download

Google provides a Linux version of Chrome as a Debian package. Linux
Mint is based on Ubuntu, which uses this package format, so the Debian
installer is the right choice for most standard Linux Mint computers.

1.  When the download options appear, choose **64 bit .deb (For
    Debian/Ubuntu)**.
2.  If a terms or confirmation window appears, review it and continue
    with the download.
3.  Wait for the file to finish downloading.

The file will usually be saved in your **Downloads** folder. Its name
will look similar to `google-chrome-stable_current_amd64.deb`.

\[SCREENSHOT: Google Chrome download options showing the 64 bit .deb
option for Debian and Ubuntu\]

> **Good to know:** Most current Linux Mint desktop computers use 64-bit
> Intel or AMD processors. If your computer is an unusual model or uses
> a different processor architecture, check its specifications before
> choosing an installer.

## Step 3: Open the downloaded installer

Linux Mint includes a graphical tool for installing downloaded software
packages. You can use it to install Chrome without typing commands.

1.  Open the **Downloads** folder. You can usually find it in the
    left-hand sidebar of the file manager.
2.  Find the file named `google-chrome-stable_current_amd64.deb`, or a
    similarly named Chrome `.deb` file.
3.  Double-click the file.
4.  If Linux Mint asks which application to use, choose the package
    installer or software installation option offered.
5.  Wait for the installer window to open.

\[SCREENSHOT: Linux Mint Downloads folder showing the downloaded Google
Chrome .deb file\]

If double-clicking opens a different app or does not start the
installation, right-click the downloaded file and look for an option
such as **Open With GDebi Package Installer** or **Install Package**.
The exact wording can vary by Linux Mint version and the software
installed on your computer.

## Step 4: Install Google Chrome

Once the package installer opens, review the details and approve the
installation.

1.  In the installer window, choose **Install Package** or the available
    install button.
2.  Enter your Linux Mint password if you are asked to authenticate.
3.  Wait while the installer adds Google Chrome to your system.
4.  When the process finishes, close the installer.

The password prompt is a normal security check. Linux Mint uses it to
confirm that you are allowed to install software on the computer.

\[SCREENSHOT: Package installer window displaying Google Chrome package
details and the Install Package button\]

> **Tip:** Keep the installer open until it confirms that installation
> is complete. Avoid restarting or shutting down the computer while the
> package is being installed.

## Step 5: Open Google Chrome

After installation, Chrome should appear in the Linux Mint application
menu.

1.  Click the **Menu** button in the bottom-left corner of the desktop.
2.  Open the **Internet** category, if it is shown.
3.  Select **Google Chrome**.
4.  Wait for the browser to open.
5.  Read the first-run options and choose whether to make Chrome your
    default browser or send optional usage information.

\[SCREENSHOT: Linux Mint application menu showing Google Chrome in the
Internet category\]

You can also use the menu's search field. Click **Menu**, type **Google
Chrome**, and select the result when it appears.

## Step 6: Sign in and bring over your bookmarks

If you already use Chrome on another computer, signing in can make it
easier to access your familiar browser setup.

1.  Open Google Chrome.
2.  Select **Sign in** if the option appears, or open the profile menu
    near the top-right corner.
3.  Enter your Google Account details.
4.  Review the sync choices and decide what information you want Chrome
    to synchronize.

Sync can make items such as bookmarks, passwords, and browsing history
available across devices, depending on your account settings. Only
enable the types of information you are comfortable syncing.

\[SCREENSHOT: Google Chrome profile menu showing the Sign in option\]

> **Good to know:** You do not need a Google Account to use Chrome. You
> can browse the web without signing in.

## Step 7: Make Chrome your default browser (optional)

If you want web links to open in Chrome automatically, you can choose it
as your default browser.

1.  Open **Google Chrome**.
2.  Open the three-dot menu in the top-right corner.
3.  Select **Settings**.
4.  Look for the **Default browser** section.
5.  Choose **Make default** if the option is available.

You may also be able to set the default browser through Linux Mint's
system settings. Open the application menu and search for **Preferred
Applications**. If that tool is available, open it and choose Google
Chrome for the web browser option.

\[SCREENSHOT: Chrome Settings page showing the Default browser section\]

## Troubleshooting: If Chrome will not install

If the installation does not go as expected, try these checks.

-   **The installer says the package is not supported:** Check that you
    downloaded **64 bit .deb (For Debian/Ubuntu)** from Google's
    official page. The package is not suitable for every processor
    architecture.
-   **The file will not open:** Open the **Downloads** folder,
    right-click the `.deb` file, and look for a package installer
    option.
-   **Linux Mint asks for a password:** Enter the password for your
    Linux Mint account if you have permission to install software. It is
    normal for the system to request approval.
-   **Chrome does not appear in the menu:** Open the application menu
    and search for **Google Chrome**. If it is still missing, check
    whether the installer reported an error.
-   **The download seems incomplete:** Delete the incomplete download
    and download the installer again from Google's official Chrome page.

If you still cannot install Chrome, check that your version of Linux
Mint is supported by the current Google Chrome package. You can also use
the Firefox browser already included with Linux Mint while you
investigate.

## Enjoy browsing with Chrome on Linux Mint

Once Chrome is installed, you can use it much as you would on a Windows
or Mac computer. Download the official Debian package, install it with
Linux Mint's package installer, and sign in only if you want your
browser information synced across devices.
